In memory, name the three parties like this:
- **Laptop**: the laptop and the Claude Code session running on it. Older notes and the docs call it "Dev box".
- **GPU box**: the other machine and its Claude Code session.
- **Priyansh**: the person working with both sessions. Pronouns aren't stated, so use they/them.

**Why:** Priyansh asked for this on 2026-10-25. Their first name is the one allowed exception to "no real names beyond the GitHub
handle" in this public repo; the handle priyansh1210 already contains it. Any other person's name, or Priyansh's surname, still
never goes in memory.
**How to apply:** write new memory with these names ("the Laptop merged...", "Priyansh decided..."). Don't write "the user", "Dev
box" or "me" when "Laptop" is meant. The docs (README, PLAN, machines.md) still say "Dev box"; that's fine outside memory.
