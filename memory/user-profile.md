Priyansh is the repo owner (GitHub: priyansh1210). Pronouns not stated: use they/them.

They are building `pehleaap`, an 8-week portfolio/research project: open turn-taking models
(end-of-turn, barge-in vs backchannel, hold intent) plus a benchmark for Hinglish voice agents
on 8 kHz Indian phone lines. The audience is voice-AI platform companies, so the framing is
"training recipe + benchmark they can rerun on their own call data", not a production model.

They work on Windows (PowerShell), write short messages, and asked for an exhaustive "ultraplan"
up front. They will recruit 40+ adult speakers (friends, classmates, family) for consented recordings.
